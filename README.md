# 🤖 VisTouch - Analyze complex robotic contact data easily

[![Download VisTouch](https://img.shields.io/badge/Download-VisTouch-blue)](https://github.com/testingzenz-sys/VisTouch)

VisTouch provides a complete view of how robots interact with objects through touch. This dataset combines high-definition vision, tactile sensor feedback, and audio recordings. Researchers and developers use these files to train machines to understand sliding contact. You can use this software to view, filter, and export data samples for your own machine learning projects.

## 📂 Understanding the Data Structure

The software organizes data into folders by date and test condition. Each folder contains three distinct file types.

*   Vision: Video files showing the robotic finger against the surface.
*   Touch: CSV files containing pressure values from the tactile sensors.
*   Audio: Waveform files capturing the sound of the contact.

The application automatically merges these files when you select a recording. This saves you the effort of manual alignment.

## 🔧 Troubleshooting Common Issues

If the program fails to load, check these common points.

*   The program does not open: Ensure you installed the latest version of the .NET Framework from the Microsoft website.
*   Video playback stutters: Close background applications that consume high amounts of memory.
*   Missing data streams: Verify that your storage drive remains connected to your computer during playback.
*   Graphics errors: Update your graphics card driver through the device manager.
